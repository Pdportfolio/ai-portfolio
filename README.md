## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.

## Chat (Groq)

The in-site assistant is a Next.js route at `/api/chat`. It streams replies from Groq using the resume data in `app/lib/content.ts` as the system prompt. There is no Hugging Face Space in this path.

Add `GROQ_API_KEY` to `.env.local` for local development (that file is gitignored). Before deploying, add the same variable in Vercel → Project Settings → Environment Variables.
